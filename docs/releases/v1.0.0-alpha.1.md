# JAVM 1.0.0-alpha.1

这是 React、Mantine 与官方 Neutralinojs 重构后的首个 Windows x64 预发布版本，供体验和反馈。

- 接入本地媒体库、目录扫描、筛选、收藏与资料维护。
- 提供资源查询、下载、资料补全和播放流程。
- 增加片库备份恢复、目录断线重连及链接注册。
- 精简 FFmpeg、MediaInfo 和 curl 由独立 GitHub Actions 从源码构建，主程序按固定版本和 SHA-256 复用。
- 同时提供便携 ZIP 和 Inno Setup 安装 EXE，两者包含相同运行文件。

## 下载与安装

- `windows-x64-setup.exe`：当前用户安装，支持快捷方式、升级与卸载。检测到缺少 WebView2 时需要联网安装微软运行时。
- `windows-x64-offline-*.zip`：解压到新目录后运行根目录的 `JAVM.exe`。工具已内置，电脑仍需安装 WebView2 Runtime。
- `SHA256SUMS`：下载文件的 SHA-256 校验值。
- `build-manifest.json` 和 `THIRD-PARTY-NOTICES.html`：构建来源、依赖记录与第三方许可；精简依赖的对应源码及编译配置见其中链接。

## 使用前须知

- 这是 alpha 版本；使用前请备份资料和数据库。安装、升级及卸载默认保留用户数据。
- 本版程序和安装包未使用 Windows 代码签名证书签名。
- 仅发布 Windows x64；当前没有新增 macOS、Linux 或 ARM64 原生安装包。
- 不提供字幕获取、本地字幕关联或多语言音轨选择。
- 站点访问、人工验证、外部服务兼容性及真实 NAS 长期运行仍可能受环境影响。
- 稳定版更新检查不会将 alpha 作为正式更新推荐。
