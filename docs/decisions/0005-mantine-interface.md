# 原型2落地为正式前端

日期：2026-10-09

用户确认以 `docs/prototypes/javm-mantine` 为界面依据，组件继续使用 Mantine；图片预览沿用旧版图箱。范围仅包含界面及部分交互，刮削、下载和播放业务暂不实现。用户进一步明确移除 mock 数据，默认入口应与正式应用一致。

## 实现

- `frontend/src/app` 提供窗口外框、页面导航、Velvet 深浅色主题和本机界面偏好。
- `frontend/src/features` 按媒体库、发现、下载、资源、目录、设置和影片详情分组。正式代码不导入原型目录。
- 所有列表初始为空，统计取当前列表长度。无预填影片、演员、资源、目录、任务、假进度或假服务状态。
- 缺少元数据时显示未知或未填写，不按影片 ID 推导演员、日期、厂商、分辨率和文件路径。
- 主题、侧栏折叠和卡片点击偏好使用本地存储；业务设置仍属于未提交的表单，保存入口明确提示服务未接入。
- 导入使用系统目录选择器，确认弹框展示所选路径与可调整的导入选项；下载表单保留输入、校验和选项展开。提交不会创建虚构记录或触发扫描、下载、数据库操作。

## 图片预览

旧 Vue 版本的 `useImagePreview.ts` 使用 `@fancyapps/ui`。本次保留 Fancybox 6.1.14，使用 React 上下文统一打开实际图片，支持封面与截图联看、切图、缩放、全屏入口、缩略图、幻灯片和键盘操作。

Fancybox 打开期间暂停 Mantine 抽屉的焦点约束和 Escape 关闭。关闭图片后焦点回到原图片按钮，抽屉保持打开；组件卸载时销毁所属图箱实例。图片标题按纯文本转义，不解释为 HTML。图片保存和删除仍需文件服务，当前不提供伪成功操作。

## 桌面边界

保留官方 Neutralino 初始化入口，原生 API 集中于 `platform/neutralino`。无边框窗口的拖动、最小化、最大化和退出调用官方 API，浏览器入口禁用这些原生窗口按钮。当前关闭窗口直接退出，托盘功能仍未实现。

选择媒体目录调用官方 [`os.showFolderDialog`](https://neutralino.js.org/docs/api/os/#osshowfolderdialogtitle)，只增加该方法的原生权限。添加入口只显示应用弹框，点击“选择文件夹”或“更换目录”才打开系统选择器；选择期间禁止重复请求和关闭确认弹框，取消不清空原选择。没有选择目录时禁止提交，不生成虚构路径。
