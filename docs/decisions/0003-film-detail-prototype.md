# 影片详情重设计

日期：2026-10-08。范围：可交互原型，不迁移正式业务。旧版对照为 `origin/main` 的 `VideoDetailDialog.vue`、`MagnetList.vue`、`CaptureCoverDialog.vue`、`DeleteVideoDialog.vue`。

## 交互安排

详情仍从片库、发现和资源结果打开右侧抽屉。默认阅读，主动点击编辑才显示表单；播放继续打开独立浮窗，关闭详情返回原入口。主操作使用与当前界面一致的按钮，低频图片、文件操作放进更多菜单和右键菜单。保留可见菜单入口和键盘操作，不恢复影片多选、通知或页面介绍文字。

上方为封面、片名、编号、评分和常用操作；下方分为“资料与截图、资源链接、本地文件”。截图直接展示在默认页；管理图片时才打开选择窗口。演员、厂商、系列、导演、分类进入发现页的对应作品列表。

900px 抽屉在首屏并排展示资料与截图；窄于等于 800px 时改为上下排列。编辑、图片管理与评分关闭后回到原操作入口；Escape 只关闭当前弹层。手动匹配进入统一资源搜索并按需打开补全窗口，发行日期与厂商的缺失判断和应用结果读取同一份资料，已有值显示“保留”；完整字段仍通过“编辑全部资料”处理。详情资源与统一搜索共用示例数据和下载去重逻辑，避免同一在线链接反复入队。

| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 标题、原始名称、番号、发行日期、时长、导演、厂商、演员、类别、评分、分辨率 | 资料展示和完整编辑表单；另补系列编辑。取消不写入，未保存离开提供放弃入口；保存同步片库与关联浏览 |
| 文件名限制、番号重复                                                       | 保留标题校验和会话内番号重复检查                                                                 |
| 评分                                                                       | 点击评分进入编辑，也可清除；2026-10-10 正式界面按用户要求统一为 0–5 分，0 表示未评分             |
| AI 识别番号、探测时长                                                      | 编辑中按需调用；原型用文件名正则和固定示例时长展示结果，不调用 AI 或 FFmpeg                      |
| 自动与手动刮削                                                             | 一键补全缺失示例资料，保留已有字段；更多菜单的手动匹配进入现有刮削页并带入影片                   |

| 封面放大、获取、从视频选取、删除                                           | 封面右键和可见更多菜单；更换与删除同步片库中的封面展示                                           |
| 截图放大、上一张／下一张、清空                                             | 默认展示六张安全场景截图，沿用查看器；右键处理单张，管理菜单处理整组                             |
| 选取截图、获取封面与截图、长截图                                           | 按需打开图片窗口；选择结果更新当前会话的图片和文件列表，支持取消                                 |
| 磁力排序与复制                                                             | 资源标签直接展示结果，按推荐、体积、日期排序；磁力复制至剪贴板                                   |
| 查找视频链接                                                               | 当前页可查阅结果；查找更多进入现有资源刮削页                                                     |
| 视频下载                                                                   | 在线资源加入已有下载任务队列，并显示已在队列状态                                                 |
| 播放                                                                       | 继续使用本版独立播放浮窗和多窗口行为；外部播放器的实际调用留待桌面接入                           |
| 打开目录、复制路径                                                         | 本地文件标签展示媒体和资料；打开文件夹在原型内呈现目录内容，路径复制使用浏览器剪贴板             |
| 删除视频／仅删除刮削数据                                                   | “移除与清理”区分仅移出片库、清除资料、删除视频及关联文件；默认仅移出，均需确认                   |

## 原型边界

新交互仍只修改当前会话的示例状态。图库、资源与元数据均为安全虚构内容；资源 URL 使用无效示例域名或虚构磁力值。没有实际读取视频、运行下载器、刮削网站、调用 AI、生成图片、打开资源管理器或删除磁盘文件。剪贴板复制是真实的本机操作。

未接入真实文件的作品权限、来源验证等待、后台取消、持久化、改名后的路径同步和事务恢复继续在正式重构阶段实现。图像选择窗口中的多图选择只用于取图，未恢复媒体库影片多选。
