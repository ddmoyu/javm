# ADR 0025：JavBus 演员、分类名单与网站影片数量

- 日期：2026-10-11
- 状态：已接入源码；真实目录和显式计数格式已确认，采集覆盖以快照清单为准
- 依据：用户提供演员目录、演员作品页、分类目录及分类作品页，要求沿用多列 CSV，记录网站影片数并按数量排序；导演、发行商和制作商从已有影片资料汇总。

> 2026-10-12：AVWikiDB 已按用户要求移除，发现页只使用 JavBus，见 [ADR 0027](0027-javbus-only-discovery.md)。下文涉及 AVWikiDB 的内容仅为历史记录。

## 来源与维度

`/actresses` 和 `/uncensored/actresses` 是两个演员目录，目录中的 `/star/{id}` 或 `/uncensored/star/{id}` 是对应作品列表。`/genre` 是分类目录，`/genre/{id}` 是分类作品列表。代码中预留的 `/series/{id}`、`/director/{id}` 路径不能视为已取得可用链接；当前这两类 CSV 均为空。

保留现有 AVWikiDB 五类 CSV 的原名、中文显示名、明确别名及名单。新目录记录以 `(kind, lane, source_id)` 区分身份，JavBus ID 不与 AVWikiDB ID 互换。同名不同 ID 继续由用户选择；没有明确匹配时不取第一项。获得 JavBus ID 后直接打开作品路径，避免每次重复搜索演员名称。

女演员的更新使用 JavBus 两个分区，每次只处理一个分区、最多八页，每页最多一百项。保存分页游标及本轮来源顺序；未读完继续同一分区，读完切换分区。保留未在本轮读到的旧条目，失败或取消不推进游标。男演员保留原目录，不能从影片详情里的通用演员链接猜测男女归属。

发现页增加发行商入口。导演、系列尚无已保存的 JavBus 链接，按用户要求暂时移除这两个发现入口，待后续明确接入链接再恢复；名单、缓存和影片元数据保留，从影片详情点击这两类字段仍可筛选本地已收录作品。制作商、发行商可使用已保存的 JavBus 身份读取对应作品；未获得身份时沿用已有的有限候选定位。详情关系只取信息区；不额外遍历作品来填充名单。

## CSV 格式

生产桌面写入 `%LOCALAPPDATA%/JAVM/catalogs/javbus`，按维度分别保存 `actresses.csv`、`maleActors.csv`、`directors.csv`、`studios.csv`、`labels.csv`、`series.csv` 和 `genres.csv`。另有 `data/catalogs/javbus` 采集快照，沿用同一 CSV 验证器；其中男演员文件名是 `male-actors.csv`。生产包在 Catalog Worker 中读取快照，开发模式不请求这些真实 CSV。

CSV 使用 UTF-8 BOM、CRLF 和双引号转义；按文本导入电子表格软件。字段如下：

| 字段                 | 含义                                                       |
| -------------------- | ---------------------------------------------------------- |
| `source`             | 固定 `javbus`                                              |
| `kind`               | `star`、`director`、`studio`、`label`、`series` 或 `genre` |
| `lane`               | `censored` 或 `uncensored`                                 |
| `source_id`          | 当前网站和分区的来源 ID，作为文本                          |
| `name_original`      | 页面中的原名                                               |
| `name_zh`            | 人工维护的中文名，缺失留空                                 |
| `aliases`            | 明确维护的别名，以 `\|` 分隔                               |
| `translation_status` | `pending`、`translated` 或 `reviewed`                      |
| `source_url`         | 对应实体作品首页的 HTTPS URL                               |
| `category`           | 分类目录的分组名称，其他维度留空                           |
| `video_count`        | 页面明确提供的影片数，未知留空，零保持 `0`                 |
| `count_updated_at`   | 取得该数量的 UTC ISO 时间，未知数量对应空时间              |

启动时读取这些 CSV，保留人工校对字段。网络更新不覆盖已译名和已校对名，别名合并保存。数量可以随新页面增减；旧时间的数量不覆盖较新值，缺失数量不抹除已有值。内存作品分页缓存命中不刷新数量时间。

CSV 解析与导出位于 Catalog Worker，磁盘访问使用 [Neutralino 官方 filesystem API](https://neutralino.js.org/docs/api/filesystem/)。先写完整临时文件，再保留一份 `.bak` 并复制至目标；复制并非跨文件事务。缓存保存失败会反馈，CSV 保存失败保留现有内存和 JSON 缓存。CSV 解析失败时本次运行停止覆盖原 CSV，提示修正后重新启动。

## 数量与排序

只解析页面显式提供的影片数量属性、计数元素或带影片单位的总数文字。真实页面的 `#resultshowall` 显示“全部影片”及总数，`#resultshowmag` 是已有磁力的子集，不能混入总数。页数、当前页卡片数、年份、导航、脚本和作品标题数字不作为总数。没有明确总数或数量冲突时保持未知，不能用页数乘每页大小估算。

原生临时名单增加可空的网站数量列，媒体库的 `count` 继续表示本地已收录数。发现页提供“默认顺序”“名称 A–Z”“视频数量最多”；默认顺序仍保留目录顺序，数量降序在 SQL／Worker 分页前完成，同数量保留目录顺序，未知排在零之后。界面显示“× 部作品”和“本地 ×”，未取得作品总数时明确显示“数量未知”，本地服务不可用时也不显示假零。

按用户要求，应用界面不展示资料站点名称或来源编号，包括状态、提示、影片详情、刮削列表及设置；内部路由、身份与 CSV 字段不变。同名实体仍由用户选择。用户进一步明确分类选项用“有码 / 无码”区分；同一分区内有不同链接时增加分区内条目编号，保留所有链接，各自分页显示作品。不能仅因同名或缺少作品数删除记录，也不把未知数量判为无效链接。其他同名实体沿用条目编号。作品列表优先使用当前查询返回的明确总数，单一匹配项也可显示目录保存的数量；存在多个匹配项时不把目录合计数作为单个条目的总数。

同名多个来源 ID 不合计。相同 ID 的两个分区分别记录原始数值，只有两个已有分区记录均提供明确数量时才合计；任一已有分区缺失数量时显示未知。未确认的同名身份或原生别名归并涉及多个记录时不虚构合计。数量反映已获得的来源记录，不宣称覆盖未读取的分区或未收录身份。

目录缓存升级为 v6，兼容 v1–v5，保留原 CSV 名称、目录顺序、来源身份与头像索引。内置快照可在启动时恢复，缓存只保存相对于快照新增或改动的身份字段；只有数量发生变化时使用 `(维度, 分区, ID, 数量, 时间)` 紧凑记录，不复制其他不变字段，避免数万条数量更新触发缓存大小上限。紧凑记录逐条验证已知身份、数量与时间，再合并；未知身份、重复身份或非法数量拒绝。实体对象留在 Worker，页面接收目录、数量与增量缓存。目录更新和作品读取产生的名单变更串行合并，避免相互覆盖。保持现有 HTTP 有限队列、同站限频、取消和退出清理，开发版不启用真实来源或真实图片。

## 授权后的文本采集

用户确认已成年并明确继续采集演员、分类、制作商、发行商的指定文本字段。独立脚本 `pnpm catalog:collect` 仅保存身份、名称、类别分组、明确影片总数及采集时间，不下载图片、视频，也不保存作品标题、描述或原始 HTML。使用本机会话和环境代理；遇到人工验证或拒绝响应停止，不解答验证题，不伪造验证 Cookie。

演员分页实际超过 1000 页，演员专用页数上限调整为 2000，作品和其他目录原有分页限制不变。名称中的多余空白归一；单独角括号作为文本保留，标签形态的字段仍拒绝；无名称的演员身份记录在清单中，不虚构名称，也不丢弃同页正常记录。

脚本最多四个网络工作者，共享请求间隔，响应大小、请求时间、重试次数有明确上限。CSV 按批次原子替换并保留备份；Windows 临时占用时有限重试。断点保留在 `.tmp/javm-catalog`，数量逐条续采。创建 `cancel.request` 可取消，并先保存已取得的文本结果。制作商和发行商没有独立目录入口，名单来自已有资料及明确指定的列表分页；覆盖不等于全站完整名单。
