# ADR 0024：保留 CSV 名单，在线作品使用 JavBus 路径

- 日期：2026-10-11
- 状态：已接入，包含在 `20261011T022344Z` 离线包
- 依据：用户要求参考旧版 JavBus 的分类、演员、视频卡和详情路径；保留当前 CSV。另已明确授权本机后台请求真实来源，禁止显示内容。

## 范围

AVWikiDB 的五类 CSV、中文名称、别名、名单顺序和本地数量继续使用，不迁移来源 ID、不删除旧缓存。生产桌面的在线作品默认改为 JavBus；分类增加为发现页入口，复用已有 JavBus 分类目录和编号。原 AVWikiDB 读取适配器保留，但不在 JavBus 请求失败时自动反复切换来源。

参考旧版 `origin/main` 的 `src-tauri/src/resource_scrape/actor_provider.rs` 与 `sources/javbus.rs`，在当前 TypeScript Catalog Worker 中实现：

1. 演员按 CSV 原名、译名和明确别名构造 `/searchstar/{name}` 查询，兼容括号别名。搜索结果须精确匹配规范化名称；多个来源身份先由用户选择。不同网站的 ID 不互换，也不沿用旧版“未匹配时取第一项”的逻辑。
2. 已知分类使用 `/genre/{id}`。导演、制作商、系列先搜索候选作品，再校验详情的番号和对应维度链接名称，使用 `/director/{id}`、`/studio/{id}`、`/series/{id}`。
3. 作品分页为实体路径及 `/{page}`，兼容 `/uncensored` 分区；只跟随当前实体的下一页。卡片读取 `movie-box`，详情读取信息区，忽略脚本和外站导航。带发行日期后缀的作品地址完整保留，以页面内番号再次校验身份。
4. 详情继续使用现有预览、收藏保存资料及按番号查找资源入口，不增加磁力解析、下载或新 WebView 宿主。

2026-10-11 收藏图片补充：收藏完成文字与 NFO 保存后，直接采用已校验的详情，在应用级图片后台任务中下载缺失的封面与预览图，转换和解码继续在 Worker 中完成；每次最多保存 24 张图片。重复收藏保留已有封面与截图，不重复下载。图片失败或取消不撤销收藏和文字资料，保留成功图片并提示重试；详情的“获取封面与截图”按已保存的来源网页重新读取 JavBus／AVWikiDB 详情。图片提交与本地挂载刷新完成后再打开片库详情，避免首次收藏返回空图片路径。

## 生命周期与限制

- 普通请求复用常驻 libcurl 和当前代理；现有 HTTP 调度保持全局最多 4 个、同站最多 2 个、最小发起间隔 300ms。
- 定位依次尝试最多 3 个名称、2 个分区，每个搜索只读首页；非演员维度最多检查 4 个不同作品详情。整条操作最长 60 秒，每次 HTTP 请求最长 25 秒、正文上限 2 MiB。
- 作品服务保持一个活动操作和一个最新待办，切换、离页、取消和退出均等待清理，旧结果不能回写。内存保留最近 8 个作品分页及最多 64 个成功身份映射，身份缓存 10 分钟；没有匹配的名称不缓存为成功。
- 失败保留当前页；无法识别页面不冒充空列表。CSV 中的名称不保证被 JavBus 收录，不进行模糊自动关联。
- 页面解析和 CSV 查询仍在 Worker，UI 只接收卡片、关系字段和分页结果。网络日志只保留固定阶段和数值，不记录作品标题、页面正文、URL、Cookie 或代理地址。
- JavBus 403 直接反馈并结束；不能调用限定 AVWikiDB 域名的隐藏读取器。AVWikiDB 的人工验证问题不因本次切换而被标记为已解决。
- 后续按用户授权补齐受控重定向：最多 3 跳，仅限已确认的裸域名／www 与同一实体、作品和页号；全链共用 25 秒及 2 MiB 限制。正常 301／302 等状态可以继续，循环、错页、外站或验证入口均结束。实测同站 HTTP Location 只使用其 HTTPS 等价地址，详见[重定向与离线包验证](../verification/2026-10-11-javbus-302-offline.md)。

## 验证

见[本机后台与安全 mock 记录](../verification/2026-10-11-javbus-discovery.md)。真实请求只读取 HTML，未打开任何站点窗口、加载图片／视频或访问用户媒体库。发行商导航、CSV 全量名称匹配和全部分区遍历不在本轮验收范围。
