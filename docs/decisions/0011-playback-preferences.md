# 播放偏好

2026-10-09。按用户“播放偏好功能先实现”的授权接入现有设置页中的默认播放器、外部播放器路径和记住播放进度。使用现有 Mantine 组件、应用级播放入口及 Neutralino 官方存储和进程 API，不增加依赖或 C++ 服务。

2026-10-10：移除进度记忆开关，内置播放器改为默认续播，进度持久化到独立 SQLite 表，详见 [默认记忆播放进度](0015-automatic-playback-progress.md)。

## 设置与生效时机

- 默认使用内置播放器并复用现有窗口，外部程序路径为空，自动记忆每个视频的播放位置。
- 桌面端可以手动输入或选择 Windows `.exe` 的绝对路径；不接受命令行参数。保存和启动时均异步检查文件是否存在。
- 外部路径为空时调用系统关联应用；网络链接可能由系统默认浏览器打开。
- 点击“保存播放设置”后持久化，下一次播放生效；当前播放保持开始时的偏好。可以撤销未保存修改，切换设置分类保留草稿。
- 浏览器预览显示真实设置布局，但禁用选择本地程序和保存，明确提示在桌面端操作。
- 读取、校验、保存或程序启动失败均反馈错误；保存失败不更新已生效设置，取消文件选择不改变草稿。

## 播放窗口模式

按后续用户授权，播放设置增加“播放窗口模式”，仅作用于桌面内置播放器：

- **复用现有窗口**：打开不同视频时，在最近打开且尚未关闭的播放器中替换视频；没有窗口时新建。目标窗口已最小化时恢复并激活。
- **在新窗口中播放**：打开不同视频时新建独立无边框窗口，已有视频继续播放，各自拥有标题栏、控制条与媒体资源。

**同一视频只允许一个内置播放窗口**，这条规则优先于两种窗口模式。`play(source, options?)` 先在所有存活窗口中查找同一视频，找到后仅恢复、显示并激活原窗口，保留当前位置和播放／暂停状态，不替换其他窗口、不重新加载媒体。已失败的源再次播放时仍在原窗口重新加载。关闭或换片后释放原视频的窗口归属，之后可以再次打开。

视频身份按地址确定：本地路径由现有入口统一 `file://` 和路径分隔符，Windows 路径比较忽略大小写；网络使用解析后的完整 URL，保留路径大小写和查询参数。标题、格式提示和 Referer 不影响身份。同名但不同目录的文件、不同查询参数的网络链接仍是不同来源，不进行内容散列或磁盘扫描。

保存后下次播放生效，切换模式不关闭已有窗口。切回复用时只替换最近窗口，其他窗口保持不变；最近窗口关闭后使用剩余窗口中最近打开的一个。再次播放已失败的视频沿用当前窗口，不因新窗口模式额外创建实例。

主窗口管理多个独立通信会话，各子窗口的播放状态与清理相互隔离。打开过程中仍拒绝重叠请求，不积压启动任务。关闭某个播放器只收尾该窗口；显式退出应用或主入口交接给外部播放器时关闭全部内置窗口，一个窗口清理失败也继续清理其余窗口，并保留失败连接供重试。

窗口模式保存为 `windowMode: "reuse" | "new"`。旧设置缺少此字段时默认补为 `reuse`，保留其他偏好；明确的非法值报错，不重置整个设置。浏览器预览继续使用一个应用内浮窗。

## 应用级播放入口

媒体库、影片详情、本地文件和已完成下载继续调用同一个 `play(source, options?)`。主窗口的 `PreferredPlaybackController` 等待偏好读取后选择内置子窗口或外部应用。打开期间拒绝额外请求，退出或关闭可取消尚未执行的启动。

外部播放由已保存的默认播放器偏好决定。外部程序成功启动后关闭内置播放，启动失败则保留内置窗口并显示错误。外部程序属于用户选择的独立应用，JAVM 不等待其退出，也不在关闭自身时终止它。

指定程序通过 `ProcessStartInfo` 启动，文件名和媒体地址分别传递。媒体路径或 URL 是一个完整参数，中文、空格、单引号和 shell 特殊字符不会变成额外命令。不提供任意参数模板；过长地址会明确报错。该通用接口不向外部播放器传递 Referer 等请求头或播放进度。

## 内置续播

内置播放器默认读取当前视频的 SQLite 进度，在首次可定位时恢复。播放中每 5 秒节流保存，暂停、关闭、换片及正常退出时保存最新位置。最后 5 秒或播放结束后下次从头开始；外部播放器自行管理进度。

进度按实际文件或网络来源单独存储，不再保留 200 条上限。子窗口经所属主窗口调用现有官方数据库扩展，每次只更新一行，避免整份旧缓存覆盖其他窗口。旧设置的 `rememberProgress` 被忽略，旧 `javm-playback-history-v1` 记录幂等导入并保留原配置。数据结构、身份边界、失败处理与备份迁移见 [默认记忆播放进度](0015-automatic-playback-progress.md)。

## 验证

单元测试覆盖设置校验与失败、异步启动取消、历史边界、逐行写入、旧记录导入、损坏数据保护和 HLS 等待定位。`pnpm test:playback:preferences` 使用隔离的 Neutralino/WebView2 应用和合成媒体，验证实际持久化、跨子窗口续播、默认续播、旧关闭开关兼容、片尾清零，以及外部测试程序的完整单参数接收。

开发模式用环境变量 `JAVM_PLAYBACK_DEV=1` 运行同一命令。详细结果、样本与验收边界见 [播放偏好验证记录](../verification/2026-10-09-playback-preferences.md)。

多实例验证另见 [播放多窗口验证记录](../verification/2026-10-09-player-multiple-windows.md)，涵盖设置操作、本地与网络同时播放、复用目标、独立关闭、同时保存和退出清理。子窗口通过所属主窗口持久化进度，实际跨宿主效果通过桌面用例验证。
