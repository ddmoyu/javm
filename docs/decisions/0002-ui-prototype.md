# JAVM 第一轮界面原型

日期：2026-10-08。状态：可交互设计稿，待用户评审；不是正式业务实现。

## 已对齐的方向

- 媒体库突出封面，下载、刮削和目录管理使用清晰的列表与状态。
- 视觉采用暖黑、酒红与玫红，提供浅色主题。允许丰富的画面、封面和层次，不把界面做成极简表单。
- 简化的是操作路径：保留默认值、记住选择、优先一键执行，需要调整时再展开细项。
- 原型不出现 NSFW 图片或文字。封面为原创、正常着装的人物插画，片名、人物、番号、厂商和资源均为虚构示例；没有外部图片请求。
- 产品界面不展示开发阶段说明；素材来源、模拟行为和未接入能力统一记录在本文及验证记录中。
- 使用自定义窗口标题栏，包含最小化、最大化／还原、关闭按钮。
- 侧栏直接提供功能导航，移除没有切换功能的“我的片库／本地收藏”占位卡片，避免箭头造成可点击的误解。
- 侧栏底部仅保留系统设置，不提供通知入口、通知中心和通知相关设置；用户操作的即时成功／失败反馈继续显示。
- 左侧导航不显示影片数量或任务数，只保留图标和名称；具体数量在对应页面内显示。

## 预览

```powershell
pnpm prototype
# http://127.0.0.1:5174/

pnpm prototype:build
# 输出 dist/prototype，由静态 HTTP 服务加载
```

源码位于 `docs/prototypes/javm-ui/`，沿用 React、TypeScript、Mantine 与 Vite+；本轮为大列表原型增加 `@tanstack/react-virtual@3.14.13` 开发依赖，仍使用根目录单一 pnpm 锁文件。正式 `frontend/src` 仍为初始化空壳，原型没有导入 Neutralino 客户端或业务服务。重新加载页面恢复示例数据。

## 页面与交互

| 页面     | 主要内容                                                                     | 简化路径                                                     |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 媒体库   | 全部影片、海报／列表、排序筛选、收藏、详情与截图                             | 片库内搜索片名／番号／演员；详情不离开片库；右键处理单部影片 |
| 发现     | 演员、厂商、系列、导演、分类的紧凑条目与关联作品                             | 页内搜索、按名称／作品数排序、收藏筛选；单击查看作品         |
| 下载管理 | 状态、进度、暂停／继续／停止、失败重试、任务详情                             | 新建只粘贴链接；目录与画质默认沿用，改名和位置收进更多操作   |
| 资源刮削 | 影片搜索列表、完整资料与资源详情、批量队列                                   | 分页浏览多部影片；资料与截图、磁力与在线视频集中在详情页     |
| 目录管理 | 目录、增量扫描、扫描规则、片库检查                                           | 添加目录后使用默认扫描规则；检查先给建议                     |
| 设置     | 常规、下载存储、刮削、播放、网络、AI、MetaTube、日志更新                     | 按任务分组；高级设置收起；保留完整设置的组织位置             |
| 播放浮窗 | 独立进度、音量、静音、截图、影片资料；拖动、缩放、最小化、最大化／还原、关闭 | 默认单击卡片播放；可同时打开不同影片，片库保留搜索和滚动位置 |

下载完成与后处理成功分开呈现：刮削失败的任务显示“视频已保存”，直接提供“重试刮削”。等待网页验证单独展示，并提供保留现场、稍后处理和继续任务的原型。

下载管理使用 120 条固定示例任务，涵盖下载、排队、合并、刮削、暂停、失败及完成记录。工具栏与表头固定，任务区独立滚动；切换状态筛选后回到列表顶部。右侧按钮间距保持 12px，空间不足时整组换行，不压缩按钮间距。下载速度与剩余时间仅为演示数据。

## 发现页紧凑浏览（第二十轮调整）

- 对照旧版 `src/views/DiscoverView.vue` 的小头像、名称、作品数与收藏结构，删除大幅海报、条目介绍和重复标题。条目高 60px、最小宽 180px，随窗口宽度自动分列；演员与导演使用 36px 姓名占位头像。
- 工具栏提供当前维度搜索、作品数降序／名称排序和收藏筛选，滚动时保持可用；窄窗口自动换行。收藏独立于进入作品的操作，各维度分别保存收藏状态。
- 单击条目查看实际关联作品；返回时恢复查询、排序、收藏筛选、滚动位置和焦点。关联作品继续使用现有影片虚拟列表与卡片单击设置。
- 将 5,000 部虚构影片分配到 240 位虚构演员，前 12 部示例保留原演员。发现计数直接聚合当前影片资料；修改影片资料后同步更新。新增浏览状态仅在原型会话中生效，不连接旧版档案抓取、别名或持久化服务。

## 播放与多窗口（第二轮调整）

- 移除侧栏的播放页面。当前单击卡片按设置播放或打开详情；右键菜单保留明确的播放与详情入口，详情中的播放同样打开非模态浮窗。
- 不加遮罩、不锁住片库。每部影片有自己的播放状态、进度与音量；同一部影片再次点击时唤回已有窗口。
- 标题栏支持拖动和双击最大化，右下角可调整大小；标题和缩放手柄也支持方向键，Shift 加大步长。
- 每个窗口可独立最小化、最大化／还原、关闭；底部窗口条可恢复、切换或关闭窗口。切换业务页面不销毁播放器。
- 当前为浏览器内浮窗，只显示静态演示画面，没有视频解码或系统级独立窗口。正式桌面阶段使用 [Neutralino `window.create`](https://neutralino.js.org/docs/api/window/#windowcreateurl-windowoptions) 创建独立窗口。该 API 为每个窗口启动独立进程，因此数据库和下载队列必须维持唯一所有者，辅助窗口不得重新初始化它们。窗口关闭只销毁自己的播放会话。

## 大片库与加载（第二轮调整）

- 示例元数据扩至 5,000 部，编号稳定且唯一，搜索、排序和收藏覆盖完整结果集。
- 海报按行虚拟化，列表按 80px 固定行高虚拟化；只挂载可见范围和少量前后缓冲。离开页面暂停列表观察；发现页关联作品复用同一虚拟列表。
- 封面只在虚拟项目挂载后绘制。本轮使用本地 SVG 示例，没有真实图片网络请求、图片解码压力或数据库分页。不可将本轮结果描述为已经完成真实片库的性能验收。
- 搜索使用延迟渲染，筛选结果和统计缓存；查询范围覆盖完整片库，不能只查询屏幕中的项目。
- 正式实现按重构计划在数据库侧完成筛选、索引和分页，按需取元数据、封面缓存缩略图与相邻页预取。取消过期请求，限制图片读取／解码并发，避免一次加载所有原图、影片详情或 `<video>`。播放窗口按需创建，关闭后释放解码资源。
- 正式验收仍使用 1,000／10,000／50,000 条真实关联密度数据，记录设备、发布构建、冷／热缓存、首屏、检索、持续滚动帧耗时、内存和多路播放占用。阈值以实测基线对齐，不能先承诺绝对不卡顿。

## 截图与桌面交互（第三轮调整）

- 影片详情中直接展示六张 16:9 截图及时间点，点击缩略图或“查看全部”打开大图；支持上一张／下一张、底部胶片条、左右方向键和循环切换。Esc 只关闭最上层窗口，返回详情后再次按 Esc 才关闭详情。
- 海报和列表的单击行为按第九轮恢复旧版约定。海报、影片列表、下载任务和目录支持右键菜单；保留“更多”按钮，触控板、键盘或不熟悉右键的用户也有可见入口。
- 右键与“更多”共用动作定义，但使用独立定位上下文：前者跟随鼠标，后者依附按钮；窄窗口和屏幕边缘自动避让。支持 Shift+F10／菜单键、菜单方向键、Enter 和 Esc。
- 影片菜单包含播放、详情、截图、收藏、编辑、补全资料、查看文件、复制番号及移除记录。移除前确认且保留文件；从影片进入刮削或资源链接时带入对应番号，保留原有批量队列。
- 下载菜单按状态提供暂停、继续或重试；刮削失败可单独重试，保持已下载视频和 100% 下载进度。目录菜单提供扫描、扫描规则和复制路径。
- 删除侧栏标记、页面页脚、表单注释以及提示、设置、播放器中面向开发阶段的文案。对没有原生连接的操作使用正常的未配置或暂时不可用反馈，不把说明性占位文字当作下一层操作。
- 本轮新增本地生成的安全城市／风景图片 `assets/film-stills.png`，包含六个镜头，不含人物、敏感内容、文字或第三方素材。通过布局裁切展示各镜头，不修改源图；所有影片复用此素材，时间点按各自时长生成。它不是真实影片截图或 FFmpeg 抽帧结果。
- 截图仅在详情打开后挂载；关闭详情后移除图片节点。海报仍采用 SVG 和有界虚拟渲染，不为 5,000 部影片提前挂载截图、菜单内容或播放节点。
- 没有新增依赖或修改正式前端、数据库、宿主配置。复制番号／路径使用浏览器剪贴板；其余网络、文件、服务状态仍是原型内存交互。真实业务接入边界不因界面文案改为产品用语而改变。

## 内容优先与片库查询（第四轮调整）

- 移除媒体库的“私人片库”标题、介绍和“最近收藏”大块展示，初始直接显示全部影片。导入、视图切换、排序与筛选集中在紧凑工具栏中。
- 六个主页面不再重复显示页面标题、英文标语、介绍和顶部面包屑；当前页由左侧导航标识，主内容保留可访问名称。下载、目录和设置页保留必要操作按钮。设置的各分类也去掉重复标题与通用介绍，保留具体选项的帮助信息。
- 排序支持入库时间、发行年份、番号、片名、影片时长、文件大小、演员和画质，各项可切换升降序；番号采用自然数字顺序。原型按递增 ID 模拟入库顺序，正式接入时应使用真实入库时间字段。
- 筛选面板提供演员、分类、年份、画质、时长、文件大小和资料状态。前四项支持多选；同一项取并集，不同项与搜索、收藏范围取交集。选择立即生效，无单独提交步骤。
- 已选条件显示为可移除的标签，支持单项清除、重置条件和清除全部；标签自动换行。顶部范围仅提供“全部影片”和“我的收藏”；资料待补全通过筛选面板中的资料状态查询。
- 下拉列表和筛选面板分层处理 Esc；面板打开时不自动弹出第一个下拉框。窄窗口工具栏换行后，列表表头使用实测工具栏高度吸顶。
- 保留完整 5,000 条元数据的查询范围，有界虚拟渲染不变；新增独立纯查询函数及测试，没有新增运行时依赖或业务服务。

## 下载页与页底文案（第五轮调整）

- 删除下载页顶部整块统计概览；状态筛选、暂停下载和新建下载合为一行工具栏，任务表格直接跟随。单个任务的状态、进度、速度、错误原因和操作继续显示。
- 删除下载、发现和刮削页末尾的通用介绍；目录页底部的整理介绍卡片移除，“检查片库”入口放到顶部操作栏。设置页高级设置只保留名称与展开入口。
- 片库数量、具体字段说明、错误反馈和操作结果属于实际状态，不作为介绍性页脚删除。同步清除移除区域专用的桌面与窄窗口样式。

## 目录页概览清理（第六轮调整）

删除目录管理顶部的目录数、影片数、媒体占用和扫描就绪统计卡。页面直接呈现目录列表；检查片库、扫描变化、添加目录和扫描规则入口保留，扫描反馈沿用即时提示。清除统计卡专用状态和响应式样式。

## 侧栏折叠与页面内搜索（第七轮调整）

- 删除公共顶部工具栏及用户头像。搜索输入放进媒体库工具栏，只筛选当前片库，不从其他页面强制跳转。
- `Ctrl+K`／`Meta+K` 仅在媒体库可见时聚焦搜索；其他页面无此行为，弹窗、菜单和播放窗口获得焦点时不抢走输入焦点。切换页面保留本次搜索条件。
- 左侧导航支持手动折叠／展开。折叠为 70px 图标栏，保留当前页标记、可访问名称及悬停提示；窄于等于 850px 的初始窗口默认折叠，仍可手动展开。状态仅保留在当前会话。
- 侧栏底部系统设置入口在折叠后仍可使用；主题切换只在系统设置的“常规与外观”中提供。通知功能已按后续要求移除。
- 原生风格标题栏和最小化、最大化／还原、关闭按钮保留。媒体库吸顶工具栏和虚拟列表随侧栏宽度重排，搜索和排序不变。

## 侧栏品牌区域移除（第八轮调整）

移除导航顶部的播放图标、JAVM 名称和英文副标题。折叠／展开按钮进一步改为嵌在侧栏分隔线上的小箭头，取消单独的顶部按钮区域，收紧留白。按钮支持悬停提示与键盘焦点，左右方向对应收起／展开；折叠后分组仍保留间距。窗口标题栏保持独立，主导航和底部入口不变。

## 卡片单击行为（第十九轮统一）

- 设置改为“常规与外观 → 单击卡片”，在播放与详情之间切换，当前会话内立即生效。整张卡片只有一个主点击按钮，覆盖封面、片名、番号、演员、年份和空白区域，默认播放。
- 列表的缩略图、片名与普通行区域遵循同一设置；Enter／空格与对应控件的单击行为一致。发现页关联作品复用相同行为，不恢复影片选中或双击操作。
- 收藏和更多菜单作为独立按钮，不嵌入卡片的主按钮，避免连带触发。独立播放按钮始终播放，右键菜单可以直接选择详情，保留 Shift+F10 与焦点返回。

## 移除影片多选（第十一轮调整）

按用户要求移除媒体库的多选入口、影片复选框、选择状态、批量操作栏和批量移除弹窗。海报和列表只提供单部影片操作，发现页关联作品保持一致。筛选器仍可组合多个演员、分类等条件，刮削页已有的任务队列继续保留。

## 视觉约定

资源刮削已将“搜索与匹配”和“资源链接”合并为“搜索资源”，与“批量刮削”并列。搜索先显示可分页、筛选、排序的影片列表，点击整项进入该影片的完整资料、截图和混合资源详情；返回保留查询、筛选、排序、页码、滚动位置及焦点。每页按需预取资源，各影片的来源状态独立缓存。具体资源可打开规格、来源和下载方式窗口，下载、复制及右键菜单继续保留。完整交互、开源调研和后续接入边界见 [统一资源搜索与刮削设计](0004-resource-search-prototype.md)。

影片卡片悬浮或键盘聚焦时，在封面底部显示一位小数的评分与分钟时长；缺少评分时显示“暂无评分”。使用底部渐变保证文字对比度，与资料缺失标记错开；覆盖层不拦截点击，沿用单击播放／详情行为。评分为虚构原型数据，未接入资料来源。

深色底色 `#19151c`，侧栏 `#141117`，面板 `#211c24`；主要操作使用 `#cd315d`，文本强调使用 `#f985a5`。浅色主题切换为带暖色的浅灰与白色，保留玫红操作色。状态同时使用文字和颜色。

采用系统字体与原创线性图标，海报标题用本机衬线字体形成视觉对比。海报比例与网格密度适配宽度；窄窗口下保留窗口按钮、任务状态与操作，下载速度列让位给核心内容。长内容在页面内滚动，标题栏固定。提供键盘焦点、媒体库内 `Ctrl+K` 搜索、`Esc` 关闭对话框，以及减少动效支持。

## 无边框窗口

Neutralino 官方提供 `modes.window.borderless`、`window.minimize()`、`window.maximize()`、`window.unmaximize()`、`window.isMaximized()` 和 `window.setDraggableRegion()`，支持自定义标题栏与拖动排除区域。

原型中的按钮只模拟窗口状态；最大化／还原切换边距与图标，最小化和关闭显示可恢复的预览状态。标题区双击切换最大化。关闭行为跟随原型内“关闭窗口后留在托盘”的开关。

真实桌面接入时，拖动区应排除窗口按钮、输入框与其他控件；双击事件与最大化状态需要同步；默认关闭到托盘，主动退出走任务停止流程。本轮没有改变初始化宿主的窗口配置，也没有验证真实拖动、托盘、边缘缩放、DPI 或隐藏窗口队列续跑。

## 功能完整性与本轮边界

影片详情已按旧版功能重新安排为默认阅读、按需编辑的抽屉，支持完整字段编辑、关联浏览、评分、图片管理、资源排序、下载队列和文件清理选择。功能对照与模拟边界见 [影片详情重设计](0003-film-detail-prototype.md)。

以下旧功能的入口安排需要后续细化：横版封面布局、演员资料和收藏、多语言别名合并、重命名／移动、重复项对照、广告文件清理、完整来源优先级与字段覆盖规则、真实工具日志、深度链接和更新。

这些功能分别归入媒体库的视图／详情、发现的资料管理、目录的片库检查、刮削的更新调整，以及设置的对应分组。详情表单和图片选择已在当前会话中联动；仍未接入真实资源搜索或文件操作。

没有读取或写入数据库、扫描真实文件、请求影视站点、启动下载器、播放视频或操作原生窗口。各任务状态、速度、检查结果和服务状态均为固定示例或内存交互。部分设置只展示控件及保存反馈，不驱动原生业务。设置和队列仅保留在本次浏览器会话中，刷新即重置。
