# 统一应用日志与关于页面精简

日期：2026-10-10。按用户要求，应用版本只在“关于 JAVM → 当前版本”显示，移除品牌区域和设置侧栏的重复版本号，移除运行环境。下载与其他业务共用一个日志入口。

## 日志策略

- 在“设置 → 关于 JAVM → 应用日志”查看，支持按级别筛选、刷新和打开日志目录；下载页移除独立的日志区块，继续显示任务状态、进度和失败原因。
- 文件位于 `${NL_DATAPATH}/logs`。统一使用 UTF-8 JSONL，每条包含 UTC 时间、级别、模块、事件、会话 ID、递增序号及少量关联字段。
- 单文件最多 5 MiB，最多 10 个文件（含当前文件，合计上限 50 MiB），保留 7 天。写入到达大小上限或 UTC 日期变化时换文件；启动、写入、读取和每小时维护时清理。期限按文件创建时间计算，持续空闲时最多延后一次维护周期。
- 同时触及多个限制时优先清理旧文件，只识别并删除自身命名格式的 `.jsonl`，不清理目录中的其他文件。7 天是最长保留期限，容量达到上限时更早删除。
- 默认记录 info、warn、error，省略高频百分比进度与 debug。应用、下载、扫描、播放、网络测试、资料服务、设置、数据库错误和受管进程的关键事件进入统一流。

## 实现与边界

应用级 `LogService` 独立于 React 挂载；主窗口统一写文件，播放器通过已有 BroadcastChannel 回传。文件访问全部使用官方 Neutralino 异步 API，不引入日志框架、额外服务或数据库表。Neutralino 自身不另写无大小限制的 `neutralinojs.log`。

待写队列最多 500 条，每批最多 16 条，默认延迟 250ms 合并写入。队列溢出时保留错误优先，记录丢弃计数；写入失败保留有界队列，每 10 秒重试并显示错误。故障不阻断业务。正常退出在任务停止后尝试排空，最多等待 3 秒，强制结束或持久磁盘故障仍可能丢失末尾记录。

查看器最多显示近期 200 条，各文件仅读取最后 64 KiB；按二进制读取并解码，丢弃起始残行与损坏末行，避免截断中文 UTF-8 后无法返回。界面按会话和序号去重；写入结果不明确时重试可能使原始文件出现重复记录。

日志不接收设置对象、请求体或工具参数。统一隐藏 HTTP/SOCKS 地址、常见授权头、Cookie 和命名密钥，过滤上下文敏感字段，限制文本长度并去除控制字符；下载工具文本还会去掉对应任务的链接和请求头值。日志保留必要错误描述及关联 ID，不承诺识别任意非结构化文本中的所有秘密。

旧任务 `log` 字段仅用于兼容导入：最近 7 天的末尾最多 80 行分批脱敏写入，确认写入完成后通过原有修订号更新清空旧副本；失败、超时或退出时保留原数据，下次启动再试。超过 7 天的旧记录直接过期。旧行没有独立时间戳，导入时间作为日志时间，并保留任务原更新时间。新诊断不再追加到任务 JSON。

浏览器预览没有原生文件权限，显示日志仅桌面端可用。测试和验证边界见 [验证记录](../verification/2026-10-10-unified-logging.md)。
