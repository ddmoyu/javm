# 默认记忆播放进度

2026-10-10。按用户选择采用独立播放进度表，移除“记住播放进度”开关，内置播放器默认记忆所有可续播视频。此决策替代 [播放偏好](0011-playback-preferences.md) 中可关闭记忆、最多 200 条及整份配置存储的规则。

后续 [启动导入旧库](0018-legacy-database-import.md) 将当前 schema 升至 6，并将升级前备份命名改为 `pre-v6`；本页保留播放进度最初引入时的 schema 5 说明。

## 数据与身份

现有 `javm.db` 新增 `playback_progress`，媒体库 schema 从 4 升级到 5。每个具体文件或网络播放源一行：

| 字段               | 含义                                                   |
| ------------------ | ------------------------------------------------------ |
| `source_key`       | 规范化来源的 SHA-256，主键；不存原始路径或带令牌的 URL |
| `position_seconds` | 下次恢复的位置，秒；0 表示从头播放                     |
| `duration_seconds` | 记录时的视频时长，秒                                   |
| `updated_at`       | 保存位置的采样时间，毫秒                               |

不依赖 `videos` 中存在对应记录，所以未入库文件、已完成下载和网络视频也能保存。按主键读取和更新单行，不加载完整历史，不按数量淘汰记录。Windows 本地路径统一分隔符和大小写；网络使用完整 URL，保留查询参数以免不同影片串进度。同一文件改名、移动，或网络地址变化后视作新来源；暂不猜测跨地址身份，也不按片名合并不同版本。

## 保存与恢复

- 内置桌面播放器自动启用；浏览器预览不写原生数据库。外部播放器继续自行管理进度。
- 播放中最多每 5 秒保存一次，暂停、换片、关闭和正常退出时保存最新位置。一个会话最多一个写入在途和一个最新待写位置，连续更新合并。
- 保留原边界：开始不足 5 秒、剩余不超过 5 秒或播放结束时位置归零；无有效总时长的直播不记录。HLS 等待可定位区间建立后恢复一次。
- 已看完保留零位置记录；旧版导入不会重新激活已经清除的续播位置。较旧的采样不能覆盖较新的记录。
- 读取或保存失败明确报错，保留原数据及待写位置供重试，不通过删除数据库恢复。

## 多窗口和线程

每个播放器仍禁用 Extensions。主窗口为每个子窗口建立独立进度通信通道，最多接收两个在途请求，关闭会话时释放通道。主窗口调用现有 Neutralino 官方 Extension 的 `library.playback.get/save/import`；没有额外服务器或 stdin/stdout 业务协议。

数据库操作沿用原生有界后台队列与 Store 锁。一次保存仅更新当前来源，不触发媒体库全量刷新，也不改变影片元数据的更新时间。播放服务和通道均独立于 React 页面生命周期。

## 兼容与迁移

- 旧设置中的 `rememberProgress` 字段被忽略，下次保存设置时移除；原来关闭开关的用户也自动启用续播。
- 每次主应用首次读取进度时校验旧 `javm-playback-history-v1`，最多 200 条旧记录通过事务幂等导入。冲突时以数据库现有记录为准，旧配置原样保留；损坏或失败时不覆盖数据。
- schema 2、3、4 的受支持数据库先完成身份、关键列和完整性检查，使用 SQLite backup API 生成 `javm.db.pre-v5-<UUID>.bak`，再在事务中升级。升级失败回滚，原影片、关系及 NFO 数据保持完整。下载数据库结构不变。
- 测试只用合成视频与独立临时数据库，不打开真实旧数据库。

## 验证

`pnpm check`、`pnpm build`、`pnpm test` 和 `pnpm native:build` 检查代码与构建。`JAVM_MEDIA_INTEGRATION=1` 下的 `playback-history-native.integration.test.ts` 验证超过 200 条、重启恢复、并发保存、旧记录导入、非法批次回滚和 schema 4 备份迁移。

`pnpm test:playback:preferences` 与 `pnpm test:player-window` 使用带数据库扩展的隔离主窗口及禁用扩展的子窗口，验证真实设置界面、默认续播、本地与 HLS 跨窗口恢复、换片、片尾、多窗口和退出清理。
