# ADR 0022：发现页大分类对齐 AVWikiDB

- 日期：2026-10-10
- 状态：已采纳
- 依据：用户要求发现页的大分类与 AVWikiDB 一致，五类名单随包提供；头像优先 AVWikiDB，GFriends 作为兜底，并缓存到 AppData。

> 2026-10-12：AVWikiDB 已按用户要求移除，发现页只使用 JavBus，见 [ADR 0027](0027-javbus-only-discovery.md)。下文涉及 AVWikiDB 的内容仅为历史记录。

2026-10-11 后续决策：[ADR 0024](0024-javbus-discovery-works.md) 保留本 ADR 的五类 CSV 名单，在线作品默认改接 JavBus 并增加分类入口。下文的五类入口与 AVWikiDB 在线作品路径描述保留为历史决策，冲突处以 ADR 0024 为准。

## 决策

发现页按 AVWikiDB 已确认的实体目录显示五个入口，顺序为：女演员、男演员、导演、制作商、系列。

发现页入口与影片元数据字段分开维护。发行商和分类继续作为影片元数据存在，从影片详情点击时可查看相应本地作品，不重新添加为发现页的大分类。未分类的演员和同时出现在两个目录中的同名演员，均通过通用演员详情查看，不按名称猜测目录归属。

女演员使用 AVWikiDB `/actor/`，男演员使用 `/histrion/`。二者分别使用 `actresses`、`maleActors` 名单与分页位置；通用演员字段仍为 `actors`。原生查询只将各自名单内的名称关联到本地演员关系，未分类人员保留在普通媒体库筛选中。本地作品数量不等同于网站作品数量。

五类目录均加载 `data/catalogs/avwikidb` 下的 CSV。读取、校验、去重和排序在目录 Worker 内完成，前端按用户 2026-10-11 的要求每页查询和显示最多 100 项，仅保留当前页。头像仅为当前页加载，内部按 50 项串行查询，下载最多 4 个并发；切页取消旧页剩余头像任务。目录中的原名用于关联本地媒体，显示名优先使用 CSV 的 `name_zh`，并保留明确维护的别名；本次采集的中文译名仍待校对。

发现页默认使用“网站顺序”：保留内置 CSV 的记录顺序和来源目录主列表的分页顺序，不再自动按名称重排。仍可手动切换“名称 A–Z”。移除“作品最多”选项及对应查询排序，本地已收录数只作数量提示，不作为网站作品数或热度指标；官网是否将默认顺序定义为热度尚未确认。

排序缓存使用 v5，读取 v4 时从内置快照恢复顺序，保留已有增量名称、来源 ID 和头像链接，并从首页重新更新顺序。每批刷新按本轮已读页面追加，未刷新到的旧条目保留在后面；中途重启可恢复分页及顺序。名单导入原生临时表时携带位置，搜索、收藏过滤和分页均保留来源位置，别名归并取最早位置，本地独有条目排在来源名单之后。

GFriends 不提供演员名单。其文件树仅在头像兜底需要时加载到 Worker，用原名、中文名和明确别名做精确匹配；同名不同来源 ID 的演员无法确认身份，保留占位图。

## 头像与缓存

AVWikiDB 演员目录提供部分 DMM 头像链接，随包的 `portraits.json` 只保存这些链接。头像按当前可见页请求，优先 AVWikiDB 链接，缺失或下载失败后尝试 GFriends。GFriends 优先使用其官方 README 列出的 jsDelivr 镜像，之后尝试 GitHub 原始地址；两个来源均失败则继续显示占位头像，不影响名单浏览。

- 镜像索引：`https://cdn.jsdelivr.net/gh/xinxin8816/gfriends/Filetree.json`
- 原始索引：`https://raw.githubusercontent.com/gfriends/gfriends/master/Filetree.json`
- 图片使用对应来源下的 `Content/` 路径，只接受白名单 HTTPS 地址，不跟随重定向。
- Windows 缓存目录：`%LOCALAPPDATA%/JAVM/cache/portraits`。仅挂载这一个目录供本地图片显示，不随包包含真实图片。
- 已成功下载的头像以目录维度和原名作为缓存键，后续启动优先复用；成功的兜底图片同样直接复用，避免重复尝试失败的主来源。索引也持久保存，仅缺失或校验失败时重新下载。
- 图片缓存最多 1,000 张、合计 128 MiB，单张最多 2 MiB；备用索引单独最多 16 MiB。缓存淘汰当前运行期间最久未使用的图片，重启后以文件修改时间初始化顺序。
- 图片下载总并发最多四个，备用索引同时只有一个准备任务，最多两个可见页任务；页面切换取消旧任务，进度节流，退出时终止下载并清理临时文件。下载工具要求 curl 8.4 及以上，连接超时五秒、请求最长二十秒。

官方镜像依据：[GFriends README](https://raw.githubusercontent.com/gfriends/gfriends/master/README.md)。镜像可用性随网络环境变化，不承诺所有地区都能下载头像。

## 更新与兼容

- 网络请求、目录解析和排序沿用应用级异步服务及 Worker，只有一个更新任务，每批最多读取八页。
- 五类目录的中间分页每半小时继续更新，完成一轮后每天检查；内置快照采集时间用于首次检查时间，失败一小时后重试，取消后等待手动重试。
- 名单更新只提取主列表名称、来源 ID、分页链接和头像链接元数据，不在后台遍历作品详情。已知 `/null/` 编号异常条目跳过，其他结构异常、重定向、验证页、截断页面和解析失败均保留已有名单，不推进缓存游标。
- 缓存升级到 v4，保留旧版发行商和中文分类。五类目录不混入旧版 JavBus/GFriends 名称；旧缓存文件不删除。网络增量更新不覆盖 CSV 中人工维护的中文名称。
- 原生男女演员索引使用独立临时表维度，避免与旧通用演员索引混合。没有本地作品的名单名称计数为零。

## 本次范围

已完成五类离线名单接入、男女演员 CSV、目录增量更新、头像链接索引、GFriends 镜像兜底及本地持久缓存。名单上的数量仍为本地已收录数；进入条目后再按需读取在线作品及来源提供的总数。发行商和分类仍作为影片详情维度保留，不复制制作商为发行商。

开发服务器与开发版桌面仅使用安全虚构名单及占位素材，真实目录和头像适配器只用于生产桌面。界面和下载验证使用 mock，不访问真实成人作品、头像或用户数据库。具体采集条数及验证范围见数据清单和对应验证记录。

## 在线作品闭环（2026-10-10 追加授权）

用户明确要求点击发现条目后显示 AVWikiDB 对应作品，不再只查询本地片库。

- 默认进入“在线作品”，保留“本地已收录”切换。实体地址来自 CSV 的来源 ID 或目录增量更新保存的 ID，不按名称拼接网址。同名多 ID 先选择来源；发行商、分类及无法判定目录的通用演员继续显示本地结果。
- 通过现有 curl 端口请求该实体结果页，在目录 Worker 中读取主内容的 `/work/…/` 链接、标题、图片地址和同实体下一页。脚本、侧栏不作为列表数据；无法识别的验证页或结构变化显示失败，不冒充空结果。
- 点击作品后读取页面内 `__NEXT_DATA__` 的作品资料，校验番号一致，再显示完整详情。字段与路径依据 [MDCz 的 AVWikiDB 技术适配源码](https://github.com/ShotHeadman/mdcz/blob/main/packages/runtime/src/crawler/sites/avwikidb.ts) 确认；本轮未请求真实结果页。
- 资源操作复用详情中的资源链接面板；未入库预览按番号查询，不把预览 ID 当作本地作品 ID。后续复制／下载沿用既有复检流程。
- “收藏并保存资料”复用现有官方 Extension 的 prepare/commit：来源与番号去重、只补空字段、保留手动编辑、写入 NFO，返回真实本地作品。此步骤保存资料，不自动下载图片或视频；保存后可在本地已收录查看、查找资源或关联视频。
- 作品服务属于应用级目录服务，最多一个活动请求和一个最新待办；每页最多 100 项，页号最高 1000，内存保留最近 8 页。请求最长 25 秒、正文最多 2 MiB；离页取消，过期响应不回写，退出等待进程清理。HTML 和大名单处理均在 Worker。
- v4 缓存新增可选的目录 ID 映射，仅持久化增量目录身份，兼容没有该字段的原缓存；作品页面仅在本次运行中缓存。

验证范围见 [发现作品安全验证](../verification/2026-10-10-discover-works.md)。安全 mock 通过不代表已经完成真实站点兼容性验收。

## 作品访问失败处理（2026-10-10）

用户反馈直连出现 curl 35，开启代理后返回 HTTP 403。前者发生于 TLS 握手阶段，后者表示请求被拒绝，均不能解释为该演员没有作品。内置 CSV／缓存名单可离线显示，不代表在线作品请求成功。仅凭 403 不能确定是代理线路、地区规则还是浏览器验证。

核对 MDCz 的 AVWikiDB 适配与 NetworkClient 后，确认其使用站点请求头及带 Chrome 请求特征的 Impit 客户端。当前普通 curl 传输补充主应用浏览器标识、来源和页面导航请求头；不引入 Impit 或修改 TLS 验证。

作品页／详情请求返回 403 时，仅兜底一次，复用既有隐藏 Neutralino/WebView2 的启动和退出管理，并保持相同 URL 与代理。背景名单更新不启动浏览器。隐藏实例从空白页启动，安装拦截后导航；禁止图片、媒体、下载和额外窗口，不点击验证控件、不提交登录或年龄声明、不导出 Cookie。遇到人工验证、持续拒绝、其他页面跳转或 20 秒期限到达时自动结束。

成功页面只传回主内容与 `__NEXT_DATA__`，使用隔离脚本环境固定快照，每块最多 32768 字符，正文最多 2 MiB。仍在目录 Worker 中解析作品，失败保留已有结果。HTTP 401、403、重定向、限流和 curl 35 分别提示；日志只记录来源类别、阶段、数字状态和代理是否启用。

自动检查返回原实体时，允许末尾斜杠规范化以及 `__cf_chl_tk`、`__cf_chl_rt_tk`、`__cf_chl_f_tk` 临时参数，但不允许改变来源、实体、页码或其他查询条件。只有正常响应对应的新文档提交后才提取正文；读取期间发生重载则丢弃旧分块，重新等待新文档。隐藏浏览器日志仅补充文档状态码和 `cf-mitigated: challenge` 标记，便于区分普通 403 与自动检查，不能仅凭标记判断最终能否通过。

隐藏读取进一步区分宿主启动、本地控制连接、页面请求、自动验证和正文提取阶段，20 秒超时按已确认的进度提示。主文档用 frame 或已关联的请求编号识别，兼容响应事件不包含可选 frameId；主请求网络失败立即结束，只保留标准错误码。HTTP 200 若仍带挑战标记也继续等待验证，不将挑战页面作为作品。

验证见 [作品访问失败安全验证](../verification/2026-10-10-avwiki-access.md)。开发验证仅使用安全 mock，包含真实隐藏 WebView2 加载由 CDP 提供的合成文档；没有访问真实来源或验证其实际放行结果。

2026-10-11：普通 HTTP 迁移至常驻 libcurl，具体并发、缓存、请求头及取消语义见 [ADR 0023](0023-persistent-http.md)。隐藏读取适配版本 4 补齐共享 Worker 的恢复执行和脱敏网络统计；真实站点 403 尚无放行证据。

同日适配版本 5：真实隐藏 WebView 的安全合成页面复现了动画帧暂停和媒体 URL 通配符误拦脚本。使用 CDP 页面运行状态设置恢复动画帧，原生窗口仍隐藏；媒体路径使用 URLPattern，保留类型拦截。验证文档只检查人工验证标志，发现后退出，不提取挑战正文；诊断增加页面运行配置数和脚本异常次数。新增 7 项验证及局限见[运行环境修复记录](../verification/2026-10-11-avwiki-challenge-runtime.md)。

同日适配版本 6：超时开始回收后停止采集浏览器事件；主动取消、客户端拦截与真实网络失败分别统计，取消不能覆盖已有错误。主导航被重载取消时在原期限内等待新文档，不能读取旧文档，也不增加重试或延长 20 秒上限。新增日志仅记录固定来源类别、资源类型和相对时间，详见[取消处理验证](../verification/2026-10-11-avwiki-cancellation.md)。

同日适配版本 7：按官方说明单独统计已知 PAT 端点的预期 401，普通 401 和真实网络故障仍保留；补充被客户端拦截的固定资源类型与验证来源计数。此轮只修正诊断，没有确认真实挑战放行，也未重新打包，详见[PAT 诊断验证](../verification/2026-10-11-avwiki-pat.md)。

同日适配版本 8：经用户明确授权，仅使用相同隐藏宿主和应用代理访问 Cloudflare 官方安全诊断。确认端口 0 的调试参数触发原生自动化标志；改由启动器分配非零回环端口，核对端口所属 Job 后发布 CDP 端点。官方诊断改为四项检查通过，但 Turnstile 仍为 loading，不能据此宣称真实来源 403 已解决。图片／媒体拦截、20 秒总期限和失败回收继续保留，详见[官方诊断记录](../verification/2026-10-11-cloudflare-official-diagnostic.md)。

同日适配版本 9：用户在版本 8 重试仍有验证超时，另一次约 3 秒结束却缺少业务退出原因。补齐每次读取的编号与所有正常／异常／取消分支的终态，取消区分替换请求、离开视图和退出应用。新增最多 24 条脱敏请求轨迹、网络静默时长、页面／子页面运行状态和标准 Turnstile 错误码；采样仅在验证阶段异步执行，每秒至多一轮、单次执行限 250 毫秒，失败不影响业务。不读取或输出页面文本、输入值、网址或凭据，不延长超时、不点击验证。验证及日志说明见[详细诊断记录](../verification/2026-10-11-avwiki-detailed-diagnostics.md)。

同日适配版本 10：用户另行授权本机后台访问真实来源，禁止显示内容。实测确认封闭 Shadow DOM 内出现人工验证控件，普通 DOM 查询漏检而报超时。新增官方验证子页面的有界、只读无障碍树检查，确认可操作且未勾选的 checkbox 后以 `interaction_required` 自动退出；隐藏、禁用、已勾选控件不触发退出。真实复测约 13.4 秒明确结束，窗口显示 0 次，作品仍未获取成功。范围、5 项安全测试及剩余限制见[本机实测记录](../verification/2026-10-11-avwiki-local-live.md)。
