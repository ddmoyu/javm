# 可选后台运行

日期：2026-10-10。按用户要求，将固定的关闭到托盘行为改为默认开启、可保存的开关。

## 用户行为

- “设置 → 外观与交互 → 后台运行”显示“关闭窗口后留在托盘”开关，默认开启。
- 开启时，关闭主窗口隐藏到托盘，保留应用任务和播放器。托盘不可用时，执行正常退出流程。
- 每次成功隐藏到托盘后发送系统通知，说明 JAVM 仍在后台运行，并提示通过托盘菜单“退出 JAVM”彻底退出。通知异步发送，失败仅记录日志，不中断后台任务或重新显示窗口。
- 关闭时，标题栏关闭按钮及系统 `windowClose` 事件共用退出流程：停止网络测试、内置播放器、AI、MetaTube、扫描和下载，保存状态并关闭数据库，最后退出宿主。下载沿用现有暂停语义，保留可恢复材料。
- 托盘菜单“退出 JAVM”始终执行统一退出。播放窗口的关闭行为不变。
- 修改后自动保存、即时生效；浏览器预览禁用该桌面选项。

## 实现与失败语义

`BackgroundSettingsService` 在主应用启动时创建，独立于 React 页面挂载。通过官方异步 Neutralino Storage 保存 `javm-background-settings-v1`，内容为 `{ "runInBackground": true }`，不依赖 WebView 当前端口的 localStorage。

关闭入口等待首次读取及正在进行的保存，避免用户刚关闭开关就点击关闭窗口时仍进入托盘。保存期间禁用开关，仅在写入成功后发布新值；失败显示错误并保留原值。读取失败保留默认开启行为并显示错误，不自动覆盖已有配置。未开启后台运行时不等待托盘初始化。

沿用已有任务清理和失败重试路径，不直接终止主进程来绕过收尾。任务停止或数据库收尾失败时保持应用可见、提示失败，允许用户重试关闭。退出期间重复关闭不再隐藏窗口或重复启动清理。
