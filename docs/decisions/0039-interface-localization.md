# ADR 0039：界面多语言

日期：2026-10-15

状态：已实施

## 范围

支持简体中文（zh-CN）、繁體中文（zh-TW）、English（en）、日本語（ja）。
入口为「设置 → 外观与交互 → 显示语言」，默认保留简体中文。覆盖导航、设置、
媒体库、发现、下载、目录管理、资料操作、反馈、播放器控件及图片预览。
此功能仅本地化界面，不扩展字幕或多语言音轨功能。

## 决策

- 使用本地词典与 React 的 `useSyncExternalStore`，不新增运行时依赖或联网翻译。
  简体中文原文作为消息键；其余三份词典放在 `frontend/src/i18n/locales/`。
- 文案在显示边界调用 `t()`；枚举、排序值、数据库字段和第三方协议保持既有标识。
  标题、人物姓名、文件路径等内容作为插值参数保留原文，不直接调用翻译函数。
- 动态句子用完整模板和编号参数，避免拼接破坏其他语言的语序。已有后台任务消息
  仅在显示时匹配已知模板；匹配限制输入长度、缓存容量，不使用任意正则回溯。
  无匹配的技术诊断保留原文。
- 将可选 `language` 字段加入既有 UI 偏好存储，兼容旧配置。保存失败沿用原服务的
  回滚与反馈；独立播放器复用现有窗口通知和焦点刷新机制读取语言。
- 切换时更新 `document.lang`，让订阅组件重新渲染；不通过更换 React key 重建页面，
  不重启下载、扫描或播放服务。日期与数字使用当前 locale。
- Video.js 使用官方本地语言包；Fancybox 使用官方中英包及本地繁体、日语补充包。
  Neutralino 文件选择框、托盘和应用菜单在显示或更新时使用当前语言。

## 后续维护

新增界面文案须同步三份词典。选项只翻译 label，value 保持不变；用户内容不得直接
作为词典键。新增定向测试覆盖词典占位符一致性、用户内容插值、选项值不变、
旧配置兼容、偏好重载及保存失败回滚。

验证范围见 [多语言验证记录](../verification/2026-10-15-interface-localization.md)。
