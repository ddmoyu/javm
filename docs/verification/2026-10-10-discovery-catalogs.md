## 更新和本地查询

- Worker 加载内置名单后即可分页，磁盘和网络不阻塞首屏。排序、去重、JSON 和 HTML 解析在 Worker 中执行。
- 演员、分类成功更新后每天检查；其他四类共用增量任务，每半小时最多读取 8 份资料，跨分区轮换，保存分页位置和待处理队列。
- 全局最多一个更新任务。失败一小时后重试；取消当前任务不保存半份数据，不推进游标。所有更新都有进度、取消和退出清理。
- 302、403、验证页、无效或明显不完整的响应保留已有名单。不代替客户提交年龄声明，不自动完成验证码。
- 旧分类缓存可迁移；缓存损坏回退内置名单，保存失败保留当前内存数据并提示。
- 原生扩展每批最多 500 个名称导入 SQLite 临时索引；翻页不重复传整份演员名单。目录不写入媒体关系表，没有本地作品的名称计数为零。
- 发行商贯通 NFO 读取、MetaTube 字段、编辑、详情、作品筛选与刮削 NFO 写入。

## 线上替代来源核查

- AVWikiDB 的 `/maker/` 和 `/series/` 是名单索引，不是单个实体作品页。本次 DOM 核查两者首页均有 100 个实体链接，分页末页分别为 55、494；这不是总条数，也不能代表全行业全部实体。网页语言为 `ja`，尚未找到中文语言入口。
- DMM/FANZA Affiliate API 提供 `MakerSearch`、`SeriesSearch`、`GenreSearch` 等方法。开源客户端源码列出了这些方法和分页参数；官方接口在未提供凭据时返回 HTTP 400，并要求 `api_id`、`affiliate_id`。本次没有凭据，未验证完整目录响应；官方文档访问触发年龄或地区页面，没有提交新的年龄确认。
- JavDB 的第三方接口文档包含按制作商、系列等 ID 查询作品的路由。这不能证明存在可遍历所有实体的名单接口，暂不作为完整字典来源。
- 本次只核查来源，没有替换已接入的提供方或申请账号。
