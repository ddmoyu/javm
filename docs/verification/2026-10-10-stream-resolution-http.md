# HTTP 取流第一阶段验证

日期：2026-10-10。授权范围：开始 HTTP 实现，仅用安全 mock。对应 [m3u8 获取方案](../plans/2026-10-10-m3u8-resolution.md)。

## 实现范围

应用级 `ResolutionService` 提供 `submit`、取消、脱敏状态订阅、`retryCleanup` 和 `shutdown`。在 `createMainView` 创建一次，通过 Workspace 上下文提供服务，退出时收尾；没有新增页面入口。

输入为页面或 HLS URL、解析类型和可选请求头。直接链接、页面变量、JSON／嵌入页、受限 packer 文本解包共用 HLS 验证器。所有远端文本解析运行于 Worker，不执行文本中的 JavaScript。

成功结果保留主清单、所选视频及独立音频轨、请求上下文、检查时间和有效期提示。验证仅包括播放列表结构与首个可用分片、相关初始化段、AES-128 密钥的必要探测。当前只处理点播，未进行媒体解码或下载交接；状态名 succeeded 不代表全片已下载或播放验证成功。

## 保留的边界

- 没有接入真实来源、导入旧数据库、加载真实页面、图片、视频或 NSFW 内容。
- 没有运行桌面应用、真实 curl、本机网络、实际 Worker 或性能采样。因此 mock 通过不证明真实进程已无残留、不证明桌面主线程耗时小于 50 毫秒，也不证明具体站点可用。
- WebView 未实现且不会创建；仅返回回退资格。隐藏、无声、弹窗抑制、结果回传及进程清理需后续使用本地安全 mock 单独验证。
- 资源列表、用户选流、下载器的音轨选择与跨域会话、缓存和过期重新解析尚未接入。当前结果包含原始主清单及选定轨道，调用方不得直接丢弃独立音频或全局转发凭据。
- 30 秒为 HTTP 工作截止时间；取消后等待底层返回或确认清理。无可取消句柄的共享初始化和系统文件调用仍可能延长收尾。清理未确认时保留失败及重试记录，不假报操作已结束。
