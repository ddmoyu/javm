## 本轮变更

- 每次隐藏读取分配 `attempt` 编号，开始、阶段、分类诊断和结束可关联；请求行的 `request` 格式是 `attempt:序号`，不是网址或浏览器原始请求 ID。
- 成功、超时、取消、人工验证、登录要求、脚本对话框、页面跳转／不匹配、数量／大小限制、CDP 失败、清理未确认和未知错误均记录终态，不输出错误原文。取消进一步记录 `replaced`、`view_closed`、`shutdown` 或 `caller_aborted`。
- 请求摘要最多 24 条，跟踪最多 128 个请求、8 个目标／页面状态。记录固定请求类别、类型、目标类型、HTTP 状态、标准网络错误、终态和相对时间；超过上限给出 `omitted`。
- 分类区分来源文档、来源资源、挑战 iframe／脚本／flow／PAT、挑战探测域名、媒体和其他。请求 URL 只用于内存分类，路径、查询参数、Cookie、认证头、页面文字与输入值不输出。
- 记录导航／提交／执行环境重置计数、尚未完成请求数、网络静默时长、WebView 内核版本及最后失败的 CDP 方法。
- 挑战阶段每秒至多采样一轮主页面和子页面的固定布尔值、枚举和计数：webdriver、页面运行可见性、焦点状态、站点数据支持、DOM 存储访问、readyState，以及普通 DOM 中可见复选框等标志。原生窗口仍隐藏；CDP 的页面 `visibility:visible` 不代表原生窗口显示。
- 每个目标最多一个未完成采样，执行限 250 毫秒；采样不等待阻塞主读取，失败单独累计 `probeErrors`，静默执行避免把探测异常当成来源脚本错误。结束后忽略迟到结果与回收事件。
- 仅提取严格匹配格式的 Cloudflare Turnstile 六位数字错误码，不转存控制台原文；保留符合固定格式的文档 `cf-ray` 诊断 ID。不拦截或替换网站回调，不操作验证控件。

窗口策略、普通 HTTP、请求头、代理、20 秒总期限、读取成功条件和失败清理均未改变。

## 如何看新日志

优先查看同一 `attempt` 的“隐藏作品读取结束”：

| 字段或原因                                                                     | 说明                                                              |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| `reason: timeout`                                                              | 期限内未完成；结合 `idleMs`、未完成请求和页面状态判断停在哪里     |
| `reason: cancelled`                                                            | 调用方取消；`code` 区分替换、关闭视图和退出应用                   |
| `reason: interaction_required` / `authentication_required` / `dialog_required` | 已有业务检测命中相应人工操作标志                                  |
| `reason: navigation_rejected`                                                  | 主文档跳向不允许的页面或与原实体不匹配                            |
| `reason: cdp_error`                                                            | 对照运行诊断中的 `lastCdpCommand`、`lastCdpTarget`                |
| `pendingRequests` / 请求 `event: pending,response`                             | 结束时尚未收到最终完成事件；response 表示已有响应头               |
| `kind: challenge_probe`                                                        | 挑战探测域名，不能单凭其取消或 DNS 失败判定根因                   |
| `turnstileCode`                                                                | 若页面确实输出标准码，可对照官方定义；为空不等于没有验证问题      |
| `checkboxes` / `visibleCheckboxes`                                             | 普通 DOM 的存在和可见计数，仅是诊断线索，不触发新的自动退出或点击 |

没有观察到复选框不能排除闭合 Shadow DOM、尚未加载完成或其他人工验证形式。采样是有限观察，不是完整浏览器兼容性证明。[Cloudflare 官方错误码说明](https://developers.cloudflare.com/turnstile/troubleshooting/client-side-errors/error-codes/) 区分交互超时、iframe 加载失败、时钟问题和通用挑战失败；必须以实际捕获的数字码为依据。
