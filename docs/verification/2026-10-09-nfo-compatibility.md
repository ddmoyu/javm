## 覆盖证据

- NFO 样本：旧 JAVM 字段与 BOM、CDATA、裸 `&`、有效及非法数字实体、Unicode 和 GB 系列编码、大小写和别名、发行日期、不同量程评分、站点 ID 与番号分离、演员顺序和系列、分钟/秒时长、图片用途。
- 输入边界：超 2 MiB、DTD、超深节点、多个根、根外正文、截断 XML 以及非电影根节点。每次独立解析后按字节比较源文件，确认未改写。
- 实际媒体链路：生成 2 秒纯色虚构视频，使用真实 MediaInfo DLL、pugixml、SQLite 和官方 Extension 事件信封；覆盖并发上限、取消、写锁期间状态响应、增量扫描和离线恢复。
- 合成 schema 2：保留影片 ID、标题、演员及其顺序、系列、图片路径、维度收藏、别名、旧下载记录和未知表。升级前 `.pre-v4` 备份可独立读出 v2 结构与原数据。
- 迁移回滚：合成旧库中加入非绝对路径，使迁移在事务内失败；原库和备份仍保持版本 2、原数据及 `integrity_check=ok`，无残留新表。未来版本 99 拒绝处理并保留。
- 合成 schema 3：保留影片 ID 与新影片收藏；升级到 v4 后，即使 NFO 签名未变也重读旧缓存，补入发行日期及结构化评分；复用视频探测结果，峰值探测数为 0。
- 覆盖保护：手工字段即使与某次 NFO 恰好相同，后续重扫仍不覆盖；手工演员调序保留。未知扩展字段保存在原始 BLOB，损坏 NFO 不覆盖最后成功快照。
- 图片边界：有效根内图片可作为海报/横图/背景，拒绝父目录越界及通过 Windows 目录联接访问外部图片；不把演员头像当成影片海报。
- 前端资料转换：旧分辨率字符串、年份后备、图片后备和标签可显示，分页及异步服务回归通过。

补充测试发现的根外文字静默忽略、仅取首张海报和手工演员顺序覆盖问题均已修复。大 Buffer 比较改为原生逐字节比较，避免测试框架深比较超过用例时限。

## 未验证范围

所有数据库和 NFO 均为合成夹具，位于 `.tmp/media-integration-*` 和 `.tmp/nfo-fixtures-*`。没有打开、修改或删除真实用户数据库与媒体，也没有运行批量 NFO 重写。

本记录不覆盖 Kodi/Jellyfin 实际消费者导入、真实 NAS/机械硬盘吞吐、大型片库 UI 长任务、桌面窗口视觉验收或最终安装包发布。旧维度收藏和旧任务数据保留不等于相关界面及恢复业务已经接入。
