# Mantine 正式界面验证

日期：2026-10-09

## 范围

按原型2实现前端界面，移除正式入口的 mock 数据，保留旧版 Fancybox。未接入刮削、下载、播放、数据库及文件服务。

## 检查与构建

- `pnpm check`：127 个文件格式检查通过，100 个文件无 lint、类型错误或警告。
- `pnpm test`：3 个测试文件、18 项测试通过。包括既有 15 项原型规则测试，以及新增 3 项正式代码的空元数据边界测试。
- `pnpm build`：前端构建成功。主 JavaScript 约 814 kB，存在 Vite 大于 500 kB 的非阻断分包提示。
- `git diff --check`：通过。
- 正式源码不再包含样例数据生成器、虚构资源地址、硬编码媒体目录，也不导入 `docs/prototypes`。

## 浏览器

- 媒体库：全部影片与收藏均为 0；切换视图、排序、组合筛选可操作，空列表保持为空。
- 导入：改为系统目录选择器，浏览器中禁用本机目录选择并提示使用桌面应用，未选择目录时禁用提交。
- 下载：各状态计数均为 0；无效链接触发校验，有效链接也不会创建假任务。
- 资源刮削：搜索与批量页初始无结果、无队列，不显示虚构来源状态或刮削进度。
- 发现和目录：无虚构演员、厂商、目录或容量。
- 设置：深浅主题切换正常。主题、侧栏折叠和卡片点击偏好刷新后保留；业务设置保存入口不声称已持久化。
- 1280×720、800×640 下核对视觉布局；六个主页面在实际 760×540 视口中均无横向溢出。测试后恢复显示尺寸与原有深色、展开导航、单击播放偏好。

## 图箱

使用临时隔离页面给正式详情组件传入两张测试图，验证后删除该页面及脚本；测试图不会进入正式入口或构建产物。

- Fancybox 6.1.14 的工具栏、计数器和缩略图显示正常。
- 截图之间切换、左右键和缩放可操作；从封面打开时可与截图联看。
- Escape 和关闭按钮只关闭图箱，详情抽屉保持打开。
- 修复 Mantine 焦点约束重新开启时抢走焦点的问题；关闭后回到原图片按钮。
- 含 HTML 标签的图片标题显示为文本，不创建标签或执行事件。
- 隔离验证页的运行时控制台未出现错误或警告。
