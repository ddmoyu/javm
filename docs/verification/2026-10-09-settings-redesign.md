## 后续调整：统一代理与直连优先

移除“下载代理”字段，将“网络与代理”从占位界面接入应用级配置。桌面端通过官方存储 API 异步保存；下载先直连，网络失败且已启用代理时再切换一次。旧下载代理仅迁移到尚未保存的统一配置，不覆盖已保存的代理开关。

- HTTP 和 HLS 均显式控制工具的代理参数；直连成功不读取或尝试代理。HTTP 续传保留请求头与资源校验信息；暂停、取消、本地 I/O 和合并失败不触发代理切换。
- `pnpm test:downloads`：66 项全部通过，包含真实 curl、N_m3u8DL-RE、FFmpeg、SQLite 扩展和 Neutralino 宿主生命周期测试。新增真实用例覆盖直连成功、HTTP 403 后经本地代理下载、HLS DNS 失败后经本地代理下载清单与分片并合并。
- HLS 工具显式绕过回环地址。测试改用保留的 `javm-download.invalid` 域名制造 DNS 失败，由隔离的本地代理提供合成媒体，不访问真实媒体站点。该验证不代表所有线上站点或代理协议都已验证。
- 补充原生存储适配器的首次启动、读取失败和保存后重载检查，以及 HTTP 416 续传拒绝与 HLS 传输 I/O 错误检查；`download-network.test.ts` 的 28 项测试全部通过，与下载队列单元测试合计 54 项通过。存储适配器用例模拟官方 API，不等同于桌面设置页端到端测试。
- 浏览器确认下载页仅有目录与同时下载数两个输入框，网络页可以切换代理开关、编辑、撤销，分类切换保留草稿。浏览器保存保持禁用，没有写入用户实际代理配置。
- 800×640 下网络页使用分类下拉框，无横向溢出（内容宽度与滚动宽度均为 582）。
- 最终 `pnpm test`：105 项通过、65 项按条件跳过。`pnpm build` 通过，仍有大于 500 kB 的 bundle 与播放器依赖 `use no memo` 提示。
- 本次涉及的 20 个文件通过格式检查，其中 17 个 TypeScript 文件通过 lint 和类型检查。全量 `pnpm check` 最后一次记录被其他正在修改的媒体库文件格式问题阻断；没有修改这些文件来消除检查结果。命令输出保存在 `.tmp/settings-redesign/*-network.log`。
