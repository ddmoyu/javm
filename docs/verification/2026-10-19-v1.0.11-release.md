- 新增 5 项测试通过，覆盖逐组件失效、跨平台 MetaTube 补丁、来源变化、公共验证脚本变化、应用版本不影响指纹、迁移身份及缺包时不构建。工程检查仍为 0 错误、127 条既有警告，工作流静态检查通过。
