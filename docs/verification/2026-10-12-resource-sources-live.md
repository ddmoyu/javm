# 资源来源真实可用性验证

2026-10-12。用户要求把旧版 WebView 取流来源逐个接入并验证真实可用，同时明确这是办公电脑，屏幕上不得出现任何 NSFW 内容、取流 WebView 必须隐藏。本轮据此授权访问真实来源，但全程不在屏幕上显示任何页面。

## 隐藏与数据边界

- `node scripts/test-resource-sources.mjs <番号> [来源ID,...]` 启动隐藏的 Neutralino 验证宿主（`hidden`、`skipTaskbar`，经 `hiddenProcess.ps1` 以 `SW_HIDE` 创建并加入 Job Object），宿主内再按应用原流程启动隐藏取流实例；图片禁用、静音。
- 未使用浏览器面板、截图、录屏或可见窗口；未下载或播放任何媒体，HLS 检查只读取清单和 64 KiB 分片前缀。
- 报告只记录主机名、HTTP 状态、请求数、iframe 类型、清单主机、分辨率和时长，不记录标题、正文、图片或页面文字。产物位于已忽略的 `.tmp/resource-sources-*`。
- 宿主使用独立临时数据库，不读写用户数据库。

## 发现与修复

| 问题                                                       | 证据                                                                                                                              | 修复                                                                                                                           |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 多数来源约 7 秒即 `timeout`，只有 1 个请求、没有主文档响应 | CDP 每条命令固定 3 秒上限；`Page.navigate` 要等主文档响应，代理下常超时；首字节未到时 `Runtime.evaluate` 同样超时并被当作致命错误 | `Page.navigate` 与捕获循环并行，受隐藏实例总期限约束；单次执行超时继续等待                                                     |
| 页面有脚本隐藏的登录框即判定 `interaction_required`        | MissAV、ThisAV 立即失败                                                                                                           | 仅当登录/验证输入持续可见 6 秒且没有候选时才结束                                                                               |
| 脚本跳转后返回 `network_error`                             | JPTT 已收到主文档仍失败                                                                                                           | 收到主文档后忽略首个导航的 `ERR_ABORTED`；主文档到达前的瞬时连接错误自动重试一次                                               |
| 源站宕机等待满 20 秒                                       | JavEng 返回 Cloudflare 523                                                                                                        | 非验证页的 5xx 主文档立即换下一个来源                                                                                          |
| 广告位直播被当作资源                                       | MissAV 的广告 iframe 先请求直播清单，650ms 后提前返回，影片清单尚未出现                                                           | 在隐藏实例内有界读取已加载清单，识别直播、短点播和主清单；只有主文档自身的清单或不少于 10 分钟的点播才提前结束，否则等到软期限 |
| 预告片被当作影片                                           | JavCT 返回 109 秒的预告                                                                                                           | 取流结果必须含不少于 `bounds.featureSeconds`（600 秒）的轨道                                                                   |
| CDN 拒绝 HLS 检查（403 HTML）                              | 同样请求头 curl 返回 200；原生传输把 `User-Agent` 发成小写 `user-agent`，仅 Referer 时为 200                                      | `browserHeaders` 按标准大小写发送调用方请求头                                                                                  |
| 123AV 地址 404                                             | 站点移除了 `/zh/` 路径                                                                                                            | 模板改为 `/en/v/{code}`                                                                                                        |

Cloudflare 自动验证仍沿用既有策略：在期限内等待自动完成，不点击验证控件；需要人工操作时结束该来源并换下一个。本轮各来源均未出现验证页。

## 并行查找

同日按用户要求把来源查找改为并行，验证脚本也改为与应用一致的同时提交。7 个启用来源在启动后 3ms 内全部开始，22.2 秒全部结束（6 个通过，Jable 无此番号返回未找到）；串行时各来源耗时之和约 95 秒。并行运行 7 个隐藏实例期间没有出现可见窗口，也没有超时或清理失败。

影片详情关闭后自动取消查找，由 `tests/unified-resource-search.test.ts` 的新增安全 mock 用例覆盖；同文件中原先按串行提交写的断言已改为并行语义，该文件 9 项通过。没有在正式界面中手动点击验证。
