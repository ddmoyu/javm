# 1.0.7 更新修复与发布验证

日期：2026-10-15。用户授权修复更新失败、发布 1.0.7、移除 1.0.5 / 1.0.6 Release，并将并行完成的 README、安全截图及 Actions 重构一起纳入。

## 根因与修复

1.0.5 和 1.0.6 的更新适配器向公共 HTTP 适配器传入 15000ms 超时，而公共校验上限为 10000ms。请求尚未发出即被拒绝，并将取流模块的“取流输入无效”显示在关于页面。两个标签的相关实现相同。

- 更新请求直接复用公共超时上限，避免两处常量再次漂移。
- 超时、响应超限及其他传输错误转换为更新界面文案，保留原始 cause。
- 新测试保留实际 HTTP 适配器及参数校验，仅模拟底层传输、文件和原生安装端口；修复前已重现截图错误，修复后通过。
- 已安装的 1.0.5 / 1.0.6 无法通过服务端配置修复检查逻辑，README 和发布说明提供手动覆盖安装指引。无需删除个人数据。

- Windows 新增稳定版更新夹具 5 项通过：便携版成功及启动失败回退，安装版成功、启动失败回退和安装失败回退。使用实际更新助手与 Inno Setup，核对程序版本、两份 SQLite 数据库、设置和额外用户文件。
- `pnpm test`：106 个测试文件通过、53 个跳过；941 项通过、260 项跳过。跳过项不计为通过。
- `pnpm check`：格式、lint 和 TypeScript 检查通过；0 个错误、121 条既有警告。
- Windows 原生更新与安装器完整专项 17 项通过，包含上述新增的 5 项稳定版用例及既有 Beta、损坏包、退出收尾和恢复验证。
- 更新日志、旧版兼容签名和安装交接专项：11 项通过。

## 发布门槛

- 正式版和 Beta 发布必须在 Windows x64、macOS arm64/x64、Linux x64 上执行 0.5.3 原更新插件验收：下载原发布包并验签、拒绝篡改新包、安装实际新发布包、启动新 Neutralino 宿主并确认更新能力。
- Windows 安装版及 POSIX APP、AppImage、DEB 安装与失败回退测试并入发布流水线，包含 1.0.7 → 1.0.8 稳定版本跨度；任一失败阻止汇总发布。
- 旧版升级记录单独保存为 `javm-upgrade-*` CI 附件。面向用户的安装包、便携包和两代更新签名继续按既有清单发布。
- 1.0.7 公开后独立回读附件，确认 Latest 与旧更新入口，再移除 1.0.5 / 1.0.6 的 Release；保留标签用于追溯。

## 验证边界

所有夹具只使用安全虚构数据与隔离目录，不启动旧版业务、不读取真实用户片库。1.0.7 → 1.0.8 使用测试签名和安全替代程序验证更新协议、安装及回退；尚未发布真实 1.0.8，不能将夹具结果表述为未来版本的完整业务验收。0.5.3 验证使用原更新插件与实际新包，首次迁移沿用旧安装机制。

远端 CI、公开附件回读和历史 Release 清理结果将在完成后补记。
