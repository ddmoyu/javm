# 1.0.17 macOS Intel 闪退修复发布验证

日期：2026-10-31。正式版：[v1.0.17](https://github.com/ddmoyu/javm/releases/tag/v1.0.17)。公开时间：北京时间 15:34:06。

## 修复范围

- 对应 [Issue #14](https://github.com/ddmoyu/javm/issues/14)：macOS Intel 在启动、获取窗口尺寸或位置时因结构体返回调用约定错误而崩溃。
- 对锁定的 Neutralino 6.10.0 源码施加精确补丁：x86_64 的窗口 `frame` 和截图 `contentRectForFrameRect:` 使用 `objc_msgSend_stret`；ARM64 保留 `objc_msgSend`。
- 组件验证使用隔离空白窗口，覆盖 `getSize`、`getPosition`、`move`、`center` 和 `setSize`。应用打包后再次验证 ZIP 与 DMG 内的实际宿主，写入 `windowGeometry` 发布证明。
- 发布提交：`9051b7766470bdd989469ca7f01e9bed45e2bfb2`。版本为 `1.0.17`，标签 `v1.0.17` 指向已推送至 `origin/main` 的提交。

## 本机验证

- `pnpm check`：0 错误、134 条既有警告；新增检查未引入警告。
- 完整测试：123 个文件通过、57 个跳过，1,148 项通过、277 项跳过。跳过不计为通过。
- `pnpm build` 通过，保留现有分包及动态导入提示。
- 新增 ABI 专项 3 项通过，覆盖补丁位置变化时拒绝继续、Intel 隐藏返回参数和 ARM64 保持原入口；连同组件隔离与只读消费共 8 项通过，发布契约专项 24 项通过。
- 校验锁定源码归档 SHA-256 后应用全部补丁成功。19 组组件指纹中只有三个 POSIX Neutralino 发生变化，其余 16 组保持一致。
- 首轮 pnpm 自动恢复依赖时被本地预览进程占用，导致缺少模块和测试加载失败。关闭对应预览、按锁文件恢复依赖后重新检查、测试和构建全部通过，并恢复预览进程。构建生成的目录数据库变化未提交。
