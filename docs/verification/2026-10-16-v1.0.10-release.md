# 1.0.10 发布验证

日期：2026-10-16。正式版：[v1.0.10](https://github.com/ddmoyu/javm/releases/tag/v1.0.10)。

## 问题与发布范围

- 旧库导入把 `actor_works`、`facet_works` 中的发现页缓存创建为媒体库作品，造成片库数量暴增；1.0.8 和 1.0.9 均包含该路径。已将两个 Release 转为草稿，保留标签与附件；修复版发布前将 Latest 恢复为 0.5.3。
- 新导入仅从 `videos` 创建作品，发现页记录仍保存在 `legacy_records` 及原库备份中。原有的无视频资料收藏功能保持可用。
- 对已经完成的错误导入增加启动引导与设置入口，用户确认后在后台修复，支持进度、取消和重试。修复前保存当前完整数据库副本；缺少原导入前备份时保留现状并提示恢复备份。
- 仅移除证据充分、未被用户修改的最小缓存作品，保留导入前资料、旧视频、离线文件、收藏、编辑及资源、下载和刮削关联。修复与完成标记在同一事务中提交，失败或取消均回滚，不删除媒体文件。
- 按用户要求一并提交此前未提交的刮削历史跨页勾选、批量移除与失败记录清理，并发布完整的 1.0 大版本功能介绍、升级说明和下载表格。
- 发布提交为 `18b0612f8fc5463d91e4b6ad08d0117a4f8d4678`；代码、`package.json`、Neutralino 配置和标签版本一致。发布前通过干净工作区与 `origin/main` 祖先关系校验。

## 本机验证

- `pnpm native:build`：MSVC 原生构建成功。
- `pnpm check`：0 个错误、127 条既有警告；未将警告记为已修复。
- `pnpm test`：112 个测试文件通过、57 个按条件跳过；1003 项通过、276 项跳过。
- 原生旧库迁移专项：8 个文件、39 项全部通过。包含 600 个视频加 2 万及 20 万条缓存仍只导入 600 个作品，以及受影响库修复、保护数据、缺失备份、失败回滚、取消重试和重复打开。
- 使用修复前原生程序与安全合成数据库复现 6 个视频变为 206 个作品，再用修复后程序恢复到 6 个；没有使用真实用户数据库。
- 发布日志与下载表格专项 8 项通过；Git 差异检查通过。
- 初次迁移专项有两项旧断言未适配现有损坏数据库恢复状态；初次全量测试有一项新增刮削夹具未将恢复后中断任务重新入队。修正断言及夹具后，上述完整命令全部通过，保留初次失败日志。
- 安全 mock 浏览器验收覆盖修复开始、取消、重试、完成和英文结果；此项为界面流程验证，不代表真实用户片库的人工修复验收。
