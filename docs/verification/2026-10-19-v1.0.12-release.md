# JAVM 1.0.12 更新检查与镜像验证

## 范围与审查

- 正式版改读固定 Latest 静态签名清单；Beta 保留原通道规则。
- 更新元数据缓存、条件请求及限流退避；清单缓存与退避跨重启保存。
- 官方优先、GH-Proxy、GHFast、自定义 HTTPS 前缀及仅官方模式；检查、安装包、回退包共用来源配置。
- 原生下载保持官方签名、大小、SHA-256 校验；同源续传、来源切换、损坏文件、Range 重试和取消均有界。
- 人工代码复查覆盖静态清单版本判断、缓存信任边界、来源地址构造、协议和大小上限、取消清理、设置保存并发及回退包来源。已修复保存设置与启动检查的竞争、网络清理未确认时继续切换来源、损坏缓存影响退避加载、自动模式中丢失已选来源续传进度的问题；发布前未遗留阻断项。
