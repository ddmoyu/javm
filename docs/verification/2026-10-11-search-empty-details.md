# 搜索结果打开空详情修复

## 原因与调整

- `MetaTubeSearch` 在搜索无结果时会生成 `provider: ""`、标题等于番号的占位对象，计入影片数量；点击后只构造基本字段，未取得影片资料。搜索异常时也会走这条退化路径。
- 资料读取失败后的提示原本留在详情遮罩后方，用户看到的是无资料的详情页。现在空详情、番号占位详情及身份不一致的结果均不按成功打开。
- 精确番号可复用现有目录 HTTP 与 Catalog Worker，最多请求两个分区的同番号详情；使用原有详情解析器核对页面番号、地址番号及目标番号。
- 后备查询不依赖演员 CSV，不采集目录、不预取关联作品；单个在途请求、60 秒总截止时间、取消与退出等待，清理未确认时不继续请求。
- 已取得的详情在当前搜索中缓存，点击直接显示封面与预览图片等资料；收藏使用已有详情与现有图片缓存/并行获取流程。
- 未取得资料时只有真实空结果和独立的“按番号查找资源”入口，不再显示虚假的一部影片，也不允许收藏空资料。
