## 本次撤下和收缩

- 撤下字幕下载、字幕合并和 FFmpeg 字幕编码支持。当前没有字幕搜索／获取来源；合成字幕封装成功不能证明有可用的字幕业务。脚本、依赖配置和本地 FFmpeg 二进制均恢复 javm-lite-2。
- 撤下多语言音轨选择控件。当前资源查询没有提供可供用户选择的轨道清单；原有自动选取音频及音视频合并继续保留。
- 移除无实际来源的独立 JSON／JSON-LD 站点模板，以及来源评分、共识等复杂设置。保留用户选中的 MetaTube 主来源，最多从两个同番号来源补空字段，并保存实际采用的来源。
- 移除依赖尚未发布的专用更新清单的自动安装、启动确认与失败回退。保留官方发布检查和手动升级。
- 本地字幕入口明确为选择已有文件或查找视频同目录的同名文件；播放器仅在加载到有效字幕时显示选择器。该功能不依赖 FFmpeg 字幕编码。

## 验证边界

各阶段只运行本次新增的定向用例，未运行完整测试。本轮收缩后通过 TypeScript 检查、原生构建、资料补全／下载改名／官方发布 mock；实际精简 FFmpeg 的纯色抽帧、路径分页、资料来源落盘与安装脚本校验也已通过。
