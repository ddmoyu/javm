## 无用功能复核结果

| 检查项                                | 实际输入情况                                        | 处理                                             |
| ------------------------------------- | --------------------------------------------------- | ------------------------------------------------ |
| 网络字幕搜索、下载与合并              | 没有已接入的字幕来源；资源查询不提供已验证字幕轨    | 撤下下载／合并逻辑及 FFmpeg 字幕编码扩展         |
| 多语言音轨选择                        | 没有轨道探测和可选择清单                            | 撤下选择控件，保留已有下载器的自动选轨           |
| 本地字幕                              | 用户选择的已有文件或同目录同名文件                  | 保留，并明确标为本地字幕；无需 FFmpeg 字幕功能   |
| 独立通用站点适配                      | 没有实际支持并验证的独立资料来源                    | 移除通用 JSON／JSON-LD 模板和设置                |
| 多源资料策略                          | MetaTube 已有多个来源，但复杂评分和共识没有证据支撑 | 收缩为可选的同番号补空字段，默认关闭，主来源优先 |
| 自动安装更新与回退                    | 没有与当前架构配套并发布的更新流水线                | 移除自动更新链路，保留官方发布检查和手动下载     |
| 截图、文件整理、NFO／STRM、收藏与别名 | 已有本地文件、片库记录、用户输入或已复检链接        | 保留对应实际流程，不额外添加功能模式             |
